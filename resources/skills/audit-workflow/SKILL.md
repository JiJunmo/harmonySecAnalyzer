## 工作流

`项目事实 -> 组件渐进式语义探索 -> 确定性组件连接 -> 六维验证 -> Root Cause Finding`

一个 Ability/ExtensionAbility 对应一个持久语义任务，可按容量分轮接续。先识别函数局部结构，再沿完整分支路径连续分析并批量记录；普通辅助调用无需逐个建图。覆盖图按源码位置表示函数内范围，工作项保存具体条件下的进度；记录数量不等于子任务数量。已在同一步分析的范围直接保存结果，未完成范围排队。

语义 Agent 读取当前 scope、conditions、state 以及精简 coverage/transitions，只有影响当前判断的历史事实才按 work_id 查询完整结果，翻页不是完成前置条件。调用位置和进入条件区分同名函数的不同工作。显式展开或跨轮保存的同步调用保留返回及异常后续，依赖被调用结果时使用 wait_for。复用仅接受已闭合且条件状态一致的工作，循环回边保留源码依据。

步骤用 result.checked 表达检查范围，用 ranges 表达已完成或待办子范围，用 transitions 表达真实去向。pause_requested 只请求换上下文。停止理由必须有源码位置并限定范围：平台或组件边界只停止深入内部，调用后面的代码继续检查。未读代码保留待办，解析失败保留 gap。

运行时只在已登记范围、分支去向和调用后续全部闭合后生成组件语义结果。此覆盖不能证明模型已经发现所有源码分支。发现敏感操作不是停止条件；记录后继续检查后置操作和其他出口。

每组按调用顺序使用必要的 `entrypoint/reachability/control/transform/security_check/operation/dead_end` 类型保存最短证据链；“最短”只能删除无关普通节点，不能删除会改变后续安全结论的分支、转换、身份变化和安全检查。禁止无真实调用或数据关系的入口与 API 笛卡尔组合，但必须从真实组件输入沿执行关系发现操作。facts 只能是源码事实，不允许使用 `effect` 类型承载推断，解析缺口只写步骤 gaps。类型按实际证据选用，不要求每种都存在。节点之间的相邻关系由运行时根据顺序确定性生成。

## 可利用性

全部语义结果落盘后，脚本从已确认的外部入口连接组件参数映射以及身份、权限变化，只把外部可达的本地操作和成功连接的跨组件操作交给独立验证任务。未导出组件可以作为下游节点，但不能作为外部根入口。验证任务对每个操作组检查反证并记录业务意图、安全边界、安全检查 结论和六维判断；跨组件组还必须判断下游校验约束的是原始主体还是仅约束了被借权的中间组件。它可以沿当前操作组已有关系读取定性所需的全部调用链源码并使用 Atlas 核实，但不能发现新的独立操作、新增操作组、另建路径或改写已落盘语义事实。

能力定点模式会为全部 Manifest 组件创建所选能力的语义任务。能力表中的 `entry_types` 只用于提示 Agent 优先核对常见入口，不作为组件排除条件。

只有 `confirmed_vulnerability` 要求六项全部为 true。第二维“攻击者控制”同时覆盖安全关键参数受控和操作触发受控，不要求虚构参数传递。有效安全检查为 `protected_exposure`；外部可达、操作控制或操作可达被明确反证为 `no_exploitable_path`；正常公开业务且未越界为 `benign_business_flow`；基础路径成立但后续缺关键证据为 `residual_risk`；基础路径本身无法建立为 `insufficient_evidence`。`true/false` 均必须有非假设证据，没有找到证据只能使用 `unknown`。

根因身份由操作位置、关键受控参数和安全边界组成。普通分支、入口别名和能力 ID 不参与根因身份。路径只为 confirmed vulnerability 和 residual risk 生成，作为报告证据，不作为调度对象。

## Atlas 使用

从当前代码范围出发，使用 Atlas 的 search/symbol/explore/calls/path/trace/impact（当前工具下为 {{atlas_prefix}}search 等）。Atlas 缺失动态边时，围绕调用点及绑定、赋值、注册或覆写源码补全；源码完整证明时继续，部分证明时继续已确认目标并保留剩余缺口，无法证明时只记录有依据的 gap。普通条件边直接使用对应源码证据，不伪造调用关系。

继承、super、helper 和可读依赖仍属于当前组件执行链。仅真实组件通信输出 component_calls，分别保存触发控制、参数映射、主体和权限变化；停止目标组件内部展开后，继续本组件调用后续。Native/NAPI 内部实现当前不接入。
