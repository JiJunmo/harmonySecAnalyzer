解耦要点

  • 平台 ↔ 插件仅经 Plugin Contract，无领域分支；卸载插件平台仍可运行
  • 三阶段单向数据流：路径发现 → 六维验证 → PoC，只读前序、只写自有表
  • 提交必须过 Schema → 领域不变量 → 事务；PoC 非门禁，失败不阻塞完成
  • 编排图（load→pool→finalize）无阶段知识，阶段推进由 drain 调度驱动

数据所有权

  • gateway.db / gateway.log：平台 Job 索引与脱敏日志；Pi Session JSONL 归 Pi
  • run.db：插件审计事实唯一源（schema v3）；graph.db：可重建的控制游标
  • report.*：从事实库确定性生成的展示产物；保留清理不删插件事实
  • 增量基线是下次 Run 的只读输入，失败/取消/缺口不推进
