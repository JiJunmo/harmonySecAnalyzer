description: 为实际敏感操作组的安全判定提供 HarmonyOS 专有漏洞语义与有效反证。
---

模式卡用于审计能力设计、规则维护和人工复核。当前两阶段运行时不会把模式卡自动注入语义分析或六维验证 Task；验证范围由已落盘语义结果确定，源码读取只用于核实该范围内的具体实现。

模式卡不能生成任务，不能把 API 命中视为漏洞，也不能覆盖 Operation Group 证据链中不存在的事实。其内容若要影响自动化判断，必须先明确进入固定语义契约或六维验证契约，不能在运行时隐式加载。

新增模式应保持差异化，只写平台或漏洞类型特有语义。通用 Operation Group 结构、六维验证、根因聚合和结果 Schema 属于 `audit-workflow` 与 `audit-orchestration`，不得在每张卡重复实现。
